# Roadmap

Planned features, in rough order. Items marked **partner input needed** cannot start until partners have provided content or review.

## Other-language games (coming soon)

Wordplay's games are currently written in English. Other-language games will let partners customise the game for a language and its Bible text.

- **Phase 1: scripture-based games in any Bible (no translation needed for the verses).** Memory Verse and the verse-based Bible Trivia questions are built from the Bible text the player has chosen, with book names taken from that Bible. The game's own wording stays in English until Phase 2.
  - Needs: a JavaScript version of the question generator, a reference reader that accepts book names in other languages, and a script-aware word search.
- **Phase 2: translation packs, one language at a time.** Partners translate the game's wording, clues, story cards, Echo key points and keywords, and character clues.
  - **Partner input needed:** translators (native speakers), a Bible scholar to check theological accuracy, and a reviewer to test each game with real groups.
  - Each language pack is reviewed before it is released.

**How partners can take part:** see [content/languages/README.md](content/languages/README.md) for the template and the steps. Contact the project owner to start a language.

## Audio and video

- Audio for Echo, Who Said It, Memory Verse and Covenant Quest. **Partner input needed:** the licence for each audio file.
- Video for Scene Detective and Covenant Quest. **Partner input needed:** the licence for each video.

## Shared leaderboard

- Moderation tools for nicknames, and a way to report an unsuitable nickname.
- **Partner input needed:** a safeguarding review before it is opened to children.

## Content

- Who Said It for the nine books still short (Leviticus, Deuteronomy, Ezra, Nehemiah, Amos, Jonah, Galatians, 1 Thessalonians, 2 Corinthians, Philemon).
- A "who wrote this letter" game for the New Testament letters, if partners agree it fits the format.
- More Echo, Story Builder and Scene Detective content. **Partner input needed:** review of each item.

## Done
